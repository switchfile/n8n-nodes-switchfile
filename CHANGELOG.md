# Changelog

## 0.1.1

- The source code is now public at https://github.com/switchfile/n8n-nodes-switchfile, and the package is published
  from GitHub Actions with npm provenance.
- The package no longer contains the TypeScript build cache (`dist/tsconfig.tsbuildinfo`).
- Type declarations are English only.
- README: examples for common workflows.

## 0.1.0

- First release: Switchfile node with Convert File, Convert URL and Get Conversion, and the Switchfile Trigger for
  `conversion.finished` and `conversion.failed`.
